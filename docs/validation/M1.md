## Findings and fixes

| # | Finding | Fix |
| --- | --- | --- |
| 1 | **Add → preflight race.** Sonarr refreshes episode metadata asynchronously after `POST /series`; an immediate manual-import preflight rejected every file with `Invalid season or episode` (Sonarr log: add at 10:54:07.1, episode refresh finished 10:54:07.4). The UI never hits this because a human clicks seconds later; automated imports do. | `runner.ts` now waits for episode rows for the monitored seasons before preflighting (30 s cap, best-effort). Covered by the mock e2e test. |
| 2 | **15 s *arr timeout too tight.** Metadata lookups through the house VPN took 12–15 s and intermittently returned 503, surfacing 502s in the UI. | Default raised to 30 s; `DROPARR_ARR_TIMEOUT_MS` overrides per deployment. |
| 3 | **No staging cleanup.** After a `move` import the staging drop stayed behind (empty dirs, rejected leftovers). | On a successful `move` import the drop's staging folder is deleted (rejected files included) and a `cleanup` job event is emitted; error paths keep staging for inspection. |
| 4 | **Anime category was not preselected** (decision-log promise). | `pickDefaultCategory` in `@droparr/core` preselects the matching `seriesType` category in the review step; unit-tested; override still wins. |
| 5 | Validation-only: Sonarr/Radarr sample detection is runtime-relative (600 s minimum for movies / 60-min shows), so short fixtures are rejected as `Sample`. | Fixtures are 11-minute clips (`e2e/m1/gen-fixtures.sh`). Real drops are unaffected. |
| 6 | Validation-only: several well-known titles already exist in the real libraries, which silently switches imports to import-only mode. | Test titles verified absent (Dune, Severance, Cyberpunk: Edgerunners, Andor, Parasite); imports go to isolated test roots and the runner asserts the add actually happened. |

## Caveats

- The *arrs' metadata backends are flaky from the house VPN (occasional
  503/timeout on lookups). The harness retries; the UI surfaces the error and
  the user can retry. Not a Droparr defect, but worth knowing.
- Validation used isolated root folders; the same add → preflight → manual
  import machinery runs against real root folders, only the paths differ.
